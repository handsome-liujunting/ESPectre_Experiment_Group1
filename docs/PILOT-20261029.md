# October 29 pilot and experiment history

The original 24 recordings cover idle, static presence, and motion, eight captures
each. The archived copies contain the 64 per-subcarrier amplitudes after converting
raw interleaved I/Q and selecting the earliest packet in each 100 ms interval. The
sidecars give source file names, original hashes, recorded role and packet counts.

Reproduce the original import from the recorder catalogue using
`python tools/import_pilot.py <recorder-data-directory> <destination>`.
The included converted data are sufficient for validation and training.

```powershell
python -m pip install -r requirements.txt -r requirements-train.txt
python tools/validate_sessions.py --data data/pilot-20261029 --manifest data/pilot-20261029/manifest.csv
python tools/loso_eval.py --data data/pilot-20261029 --output results/pilot-20261029
```

The archived report records the original equivalent paths `data` and `results`.
All 24 captures were SHORT at about 60 seconds. The recorder's roles yield 18
training, 4 independent holdout and 2 excluded captures. The original model missed
the one seated holdout. See [pilot report](../results/pilot-20261029/LOSO-REPORT.md).

The November follow-up collected eight new 90-second sessions and first replayed
them on the original model. See [original model follow-up](../results/v2/CSI-8-session-results.csv).
A subsequent feature comparison and offline model v2 are documented in
[v2 quick start](START-V2.md).
