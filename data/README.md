# data/

One folder per label. Every session is an `.npz` plus a `.json` sidecar.

```
data/
  idle/               idle_labA_c6-01_20261112-1015.npz + .json
  static_presence/
  motion/
  interference_fan/
  interference_curtain/
  interference_corridor/
  interference_wifi/
  manifest.csv        generated by tools/validate_sessions.py — do not hand-edit
```

Naming: `<label>_<room>_<device>_<YYYYMMDD-HHMMSS>.npz`. The label in the file
must equal the folder name; the validator rejects mismatches.

Required keys in the `.npz`: `csi_data` (frames × subcarriers, float) and `label`.
Optional: `timestamps` (seconds since start). Sidecar fields are listed in
`docs/DATA-COLLECTION-PLAN.md` §3.

Do not commit raw `.pcap` captures. Do commit the `.npz` files if the total stays
under ~50 MB; otherwise commit only `manifest.csv` and the hashes.
